# Campus Canteen Feedback

## Purpose
This fictional class project explores what students think about the food and service in their campus canteen. We plan to collect survey responses and suggest simple improvements.

## Files
- project_plan.docx
- survey_draft.docx
- data_dictionary.xlsx

## Team rules
- Name files in lowercase with underscores (for example, survey_draft.docx).
- Tell the team in the group chat before changing any shared file.

## Privacy reminder
Personal records and identifiable participant data must not be uploaded.
